# AndroLuaProtect Project Instructions

## Project Overview
This is an AndroLua project designed to protect Lua 5.3.3 bytecode files via virtualization and obfuscation.

## Development Environment
- **Platform**: Android
- **Runtime**: AndroLua+ (Lua 5.3.3 Support required)

## Key Files
- `main.lua`: Application logic and bridge between UI and Protection Core.
- `layout.lua`: UI layout definition using Android widgets.
- `libs/`: Contains the virtualization engine, bytecode parser, and obfuscator.

## How to use
1. Copy the `AndroLuaProtect` folder to your Android device's AndroLua project directory (usually `/sdcard/androlua/project/`).
2. Open the project in AndroLua+.
3. Select a pre-compiled `.luac` (Lua 5.3.3) file.
4. Specify an output path.
5. Click "START PROTECTION".

## Notes
- Ensure the input file is a valid Lua 5.3.3 bytecode file (generated by `string.dump` or `luac5.3`).
- The protected output is a plain `.lua` file containing the VM engine and encrypted data.
